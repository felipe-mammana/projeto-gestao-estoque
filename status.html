💾 50MB p/ 100 imgs
📱 Timeout em móvel
🔴 Risk de falha

DEPOIS (Filesystem)

⚡ 0.5-1 segundo
💾 1MB p/ 100 imgs
📱 100% confiável
🟢 Otimizado

🚀 Como Usar (3 Passos)

Novos Itens - AUTOMÁTICO

Usuário faz upload → Backend processa → Arquivo salvo → Path no banco. Transparente, nenhuma mudança no frontend.

Dados Antigos - OPCIONAL

Execute php migrate_blobs_to_files.php para converter BLOBs existentes. Script inteligente detecta o que já foi migrado.

Development - SIMPLES

Incluir image_handler.php, usar funções saveItemImage(), deleteItemImage(). Copiar exemplos de QUICK_REFERENCE.php.
